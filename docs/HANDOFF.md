# THE SYSTEM — передача контекста для нового диалога

Личное приложение-геймификация в стиле Solo Leveling. Владелец — Никита (единственный пользователь).

- **Сайт:** https://sidneyptprosaccfij66-sketch.github.io/system-sl/
- **Репозиторий:** `sidneyptprosaccfij66-sketch/system-sl`, ветка `main`. GitHub Pages деплоит папку `dist/` (она коммитится в репозиторий).
- **Полная спецификация:** `docs/specs/2026-11-03-system-app-design.md` · **план:** `docs/plans/2026-11-03-system-app.md` · **настройка Firebase/Google:** `docs/setup.md`

## Что уже сделано
- **Игра:** XP и уровень, ранг охотника E…S, 6 характеристик (STR VIT INT MST DIS CHA — названия на английском, остальной интерфейс на русском). Задания и квесты рангов E…S, Daily Quest (привычки, стрики), повторяющиеся дела, банк идей, навыки с испытаниями. Наказания — безвредные ограничения.
- **Время:** везде Москва, 24 ч. Конец дня — `dayEndHour` в настройках (сейчас 00:00).
- **Вход:** Google через Firebase Auth. Данные хранятся в Firestore. Сайт — PWA.
- **Google Calendar:** двусторонняя синхронизация. Экспорт идёт в календарь «Quests», импорт — из выбранных календарей.
- **Интерфейс:** одна лента разделов (Статус / Сегодня / Задания / Навыки / Ещё) и меню, которое к ним переносит. Отдельные страницы: `#/more/bank|journal|settings`. Демо-режим: `?demo=1`.
- **Дизайн:** HOLO 2 (голографический HUD) включён на сайте — с 03.11.2026. Слой стилей `src/ui/theme/holo2.css` работает под классом `html.holo2`. Шрифты: набор B (Oxanium / Tektur / Onest). Печати рангов квадратные с уголками, S — красная.
- **Решения пользователя:**
  - вкладка «Все» в «Заданиях» открывается по умолчанию;
  - полоса сканирования сверху вниз убрана;
  - знак «!» нарисован SVG-фоном.

## Формулы (кратко)
- **Очки за ранг:** E1 D2 C3 B5 A8 S13; XP = очки × 10.
- **Уровни:** уровень n→n+1 стоит 100 + 50(n−1) XP. Ранг охотника: E 1–9, D 10–19, C 20–34, B 35–49, A 50–74, S 75+.
- **Daily Quest:** +3 DIS за выполнение; каждые 7 дней стрика — +5.
- **Наказания:** лёгкое — 1–3 очка штрафа, среднее — 4–8, тяжёлое — 9+. Если не отметить отбытие за 48 ч, сгорает 20 % прогресса уровня.
- **Перенос и больничные:** перенести задание можно до 12:00; больничных — 2 в месяц.

## Как устроен код
- **Стек:** React 19 + TypeScript, сборка через esbuild (`node scripts/build.mjs`). Firebase SDK подгружается с gstatic (npm не нужен).
- `src/game/` — чистая логика: возвращает `Outcome { changes, events }`, журнал (ledger) только дописывается.
- `src/data/` — хранилища: `memoryRepo` и `firestoreRepo` с пополевым слиянием.
- `src/app/engine.ts` — движок; `src/calendar/` — синхронизация с календарём.
- `src/ui/` — экраны, компоненты, эффекты (`fx/`) и темы (`theme/`).
- **Тесты:**
  - `npm test` — юнит-тесты (node:test + tsx), сейчас 98;
  - `npm run e2e` — Playwright по собранному `dist/`, сейчас 35.
- **Прототипы для просмотра** (на сайт не попадают): `node scripts/build.mjs --proto=holo` собирает `prototype-holo/` в `dist-proto-holo/`.
- **Окружение облачной сессии:** esbuild/tsx/typescript/playwright лежат в `/opt/npm-tools/node_modules`, npm-реестр недоступен. Типы React — в `vendor/types`.

## Правила работы
- Отчитываться на русском. Коммиты заканчивать строками атрибуции.
- Если пользователь просит «просто прототип для просмотра», на сайте ничего не менять.
- Перед правкой — тест (RED→GREEN). Перед коммитом — `npm test` и `npm run e2e`, затем пересобрать `dist/`.
